# Feyza Kahyaoğlu Android App

Bu proje `https://feyzakahyaoglu.com/` sitesini Android WebView içinde açan ilk sürümdür.

Özellikler:
- Siteyi uygulama içinde açar
- JavaScript ve oturum/storage desteği
- Google/Maps bağlantılarını uygulama içinde açmaya çalışır
- WhatsApp, telefon ve e-posta bağlantılarını cihazdaki ilgili uygulamaya yönlendirir
- Android geri tuşu ile site geçmişinde geri gider

Android Studio ile açıp Run diyerek telefonda/emülatörde çalıştırabilirsiniz.
